# Deadline 演示脚本

更新时间：2026-05-07

用途：给项目演示、业务验收和新同事上手时使用。本文是固定演示路径，不是能力边界扩展清单；演示时优先照脚本输入，避免现场临时需求落入未覆盖样例。

## 1. 演示口径

当前版本交付的是面向 AHU 和机房群控标准模板的受控智能改造工作台：

- 通过多轮澄清和覆盖式记忆理解需求。
- 选择最合适的模板，并生成可审阅设计摘要。
- 基于当前工程 JSON 做语义定位，用户不需要知道节点 ID。
- 用受控结构化补丁改造工程 JSON，不让 LLM 直接重写完整 JSON。
- 用候选确认和局部图高亮展示系统问什么、改了什么。
- 导出前执行结构安全和需求覆盖双重校验。
- Trace、事件流、指标和反馈能追踪每次工作流过程。

明确边界：

- 不承诺从零生成任意复杂程序。
- 不让 LLM 直接写完整工程 JSON。
- 不自动应用中高风险补丁。
- 不自动在多候选目标中替用户猜一个节点。
- 不自动接入 `copy_block` 外部边界线。
- CO2/旁通阀新增设定接线、IO/通讯点位、保护删除和设备数量变化必须 dry-run 并人工确认；CO2 自然语言接线当前稳定演示为候选澄清或 reference patch dry-run，不宣称全自动落盘。

## 3. 演示一：AHU 新建、设计摘要和 CO2 候选澄清

目标：证明“需求理解 -> 模板选择 -> 设计摘要 -> 创建版本 -> 复杂改造候选澄清”闭环，并强调系统不会在目标不唯一时乱改。

步骤：

1. 首屏开始区选择 `AHU 程序`。
2. 点击 `开始会话`。如已在顶部选择过类型，也可点击左侧 `新建`。
3. 输入需求：

```text
我要做 AHU 程序，需要直膨机、排风机、CO2 控制、新风阀和 Modbus 通讯。
```

4. 观察左侧结构化需求：
   - 项目类型：AHU。
   - 设备：直膨机、排风机、新风阀。
   - 控制功能：CO2 控制。
   - 通讯/IO：Modbus。
5. 观察模板候选和设计摘要：
   - 推荐 AHU 模板。
   - 展示已满足项、需改造项、风险项和导出门禁提示。
6. 点击第一个模板的确认按钮。
7. 等待顶部出现 `版本：v_...`。
8. 输入复杂改造需求：

```text
在控制页面新增一个 CO2 浓度设定常量，命名为 评测CO2浓度设定，固定值 800，并接入新风阀控制的比较判断动态阈值输入。
```

9. 观察结果：
   - 系统展示“请选择目标对象”或计划面板“语义定位”。
   - 候选显示为 `控制 / 比较判断 / ...`，带当前阈值、上游摘要等用户可读信息。
   - 不要求用户提供节点 ID。

演示口径：

```text
这里不是让系统猜一个比较判断直接接线。CO2 接线属于中风险结构改造，当前系统先把候选目标列出来，等工程师确认接入位置，再进入 dry-run 和风险确认。
```

验收点：

- 不需要手写 JSON。
- 设计摘要可读。
- 复杂目标不唯一时展示候选，不要求节点 ID。
- 系统没有在多候选情况下直接落盘。

## 4. 演示二：机房群控无 ID 低风险修改和局部图定位

目标：证明用户用业务语言描述目标，系统能在当前工程里定位节点、自动应用低风险补丁，并在局部图中聚焦 affected 节点。

步骤：

1. 新建会话，选择 `机房群控程序`。
2. 输入需求：

```text
我要做一个风冷热泵机房群控程序，包含水泵、旁通阀和 Modbus 通讯。
```

3. 确认推荐模板。
4. 输入低风险修改：

```text
把水泵控制里的比较判断改名为 演示节点
```

5. 观察结果：
   - 系统自动应用低风险改名。
   - 版本号变化。
   - 会话或计划区域展示本次定位目标，例如 `水泵控制 / 演示节点 / compare`。
   - 右侧局部图显示自动定位，节点高亮。
   - diff 显示修改 1 个节点。
6. 点击 `校验`。

验收点：

- 用户没有输入节点 ID。
- 系统定位到当前工程节点并创建子版本。
- 局部图按 affected 节点自动聚焦。
- 改名后当前工程语义索引能反映新名称。

## 5. 演示三：多轮记忆和中风险确认

目标：证明系统能理解“刚才那个节点”，并且中风险参数修改不会自动落盘。

前置：沿用演示二中已经把水泵控制比较判断改名为 `演示节点` 的会话。

步骤：

1. 输入：

```text
把刚才那个节点的阈值改为 3
```

2. 观察结果：
   - 系统使用最近 affected 节点定位到 `演示节点`。
   - 计划为修改 `tripPoint`。
   - 风险等级进入 medium 或需要确认。
   - 当前版本号不变。
   - dry-run 摘要显示影响节点。
3. 点击 `确认应用`，并在弹窗里再次确认。
4. 观察版本号变化。
5. 右侧局部图继续聚焦被改节点。

验收点：

- “刚才那个节点”能基于工作记忆定位。
- 中风险修改确认前不落盘。
- 确认后创建新子版本。
- 本次定位目标和 affected 节点可见。

## 6. 演示四：多候选目标选择

目标：证明目标描述不唯一时，系统用用户可读候选让工程师选择，而不是要求节点 ID。

步骤：

1. 新建或沿用机房群控会话。
2. 输入：

```text
把比较判断改名为 候选选择节点
```

3. 观察结果：
   - 会话面板显示“请选择目标对象”。
   - 候选项包含页面、节点类型、关键参数和上游摘要。
   - 不显示裸 node id。
4. 点击第一个候选的 `选择` 按钮，或输入：

```text
第 1 个
```

5. 观察结果：
   - 系统复用上一轮原始意图。
   - 应用改名补丁。
   - 版本号变化。

验收点：

- 多候选不乱选。
- 候选选择不要求用户知道 node id。
- 点击候选和自然语言“第 1 个”都可作为选择方式。

## 7. 演示五：需求覆盖门禁

目标：证明“JSON 合法”不等于“满足用户明确需求”；覆盖缺失时会阻塞导出。

步骤：

1. 新建会话，选择 `AHU 程序`。
2. 输入需求：

```text
AHU 需要过滤网报警和防冻保护，通讯走 Modbus。
```

3. 确认模板。
4. 点击 `校验` 或直接尝试导出。
5. 观察需求覆盖报告。

期望：

- 结构校验可以通过或只提示非阻塞项。
- 需求覆盖报告会提示过滤网报警或防冻保护缺少可证明线索。
- 导出被阻塞。

演示口径：

```text
这里证明系统不会只因为 JSON 结构合法就导出。用户明确提出的业务需求如果找不到证据，会进入需求覆盖门禁，防止把潜在缺失留到下一阶段。
```

可用后端验收命令：

```powershell

```

工作台演示输入可采用：

```text
把节点 22a27d1 的物理输入通道改为扩展模块 1、通道 31。
```

期望：

- 风险等级为 high。
- dry-run 不保存版本。
- 确认摘要提示点表字段和值、通道/地址/对象号冲突和现场接线/通讯表复核。

演示口径：

```text
这是高级调试式输入，包含内部节点 ID。普通用户主流程不需要节点 ID；点位修改属于高风险，必须结合现场点表复核。
```

## 9. Trace 和反馈演示

目标：证明系统过程可追踪。

步骤：

1. 完成任意一次会话。
2. 打开 `版本 / Trace / 反馈`。
3. 查看：
   - `事件流`：工作流步骤、版本创建、校验完成。
   - `Trace`：trace id、用户输入、事件数量、失败事件、LLM 调用摘要和关键产物摘要。
   - `指标`：事件、LLM 成本和趋势。
   - `反馈`：提交当前演示反馈。

推荐反馈内容：

```text
演示验收：需求理解、模板选择、设计摘要、语义定位、候选选择、局部改造、校验和导出链路通过。
```

## 11. 常见现场问题

导出按钮不可用：

- 先看结构校验是否存在 error。
- 再看需求覆盖报告是否存在 blocked。
- 如果用户需求明确要求防冻、过滤网报警、旁通压差等，而当前工程缺少证据，阻塞是预期行为。

为什么候选列表里不显示 node id：

- 普通用户不应该被要求理解内部节点 ID。
- 候选会显示页面、节点类型、关键参数、上游/下游摘要。
- 高级调试时仍可输入明确节点 ID，系统会优先尊重显式 ID。

LLM 不可用：

- 低风险规则 planner、语义定位和候选选择仍可用。
- 复杂结构改造会返回业务候选或需要补充页面、业务对象、接线位置和值的追问。
- 真实 LLM 演示前必须配置 `.env` 中的 `DEEPSEEK_API_KEY`。

局部图没有显示全量工程：

- 这是预期行为。前端只加载预算受控摘要，默认聚焦 affected 节点和相关页签，避免拉取上千个节点的完整 JSON。

为什么 CO2 接线没有直接自动应用：

- CO2 接线通常涉及新增节点、启用动态输入和连线，属于中风险结构改造。
- 当前稳定演示路径是展示候选并等待工程师确认目标。
- reference patch plan 已通过 dry-run 评测，后续要自动形成确认计划还需要更多 AHU 真实样例校准。

现场不要演示的内容：

- 从零生成任意复杂工程 JSON。
- 自动删除保护链路。
- 自动复制功能块并接全部外部线。
- 无点表依据批量改 IO/通讯地址。
- 在多候选情况下要求系统“随便选一个”直接落盘。
